# 使用说明

登录后在侧边栏选择已有会话，或点击新建任务并浏览服务器真实文件夹。会话菜单支持重命名和归档；归档保留原生历史，正在执行、排队或被其他客户端控制的会话不能归档。

切换会话时，文字草稿、指令块和待发送附件分别保留在原会话；目标与队列只显示当前会话的内容。未发送草稿只保留在当前页面，刷新或关闭页面后不会恢复。

聊天占据主要空间，执行现场通过标题栏按钮打开。普通内容直接发送执行，Enter 发送，Shift+Enter 换行；中文输入法确认不会误发送。模型菜单内选择模型，再在右侧选择推理强度。

## 指令与目标

`/` 菜单选中的指令是独立元素，删除时整块移除，输入框只编辑参数。命令记录和普通聊天分开显示，保留操作状态与结果。仅识别下表中的完整指令名；其他 `/` 开头的内容（如 `/tmp/report.pdf`、`/goal/report.md`）按普通文本发送，可携带附件。输入指令名后按空格或从菜单确认才转换为指令块，继续输入路径不会被提前截断。

| 指令 | 行为 |
| --- | --- |
| `/goal 目标内容` | 设置目标并持续推进 |
| `/goal` | 查看目标 |
| `/goal pause`、`/goal resume`、`/goal clear` | 暂停、继续、清除 |
| `/compact` | 原生上下文压缩，保留网页聊天历史 |
| `/plan`、`/plan 需求` | 进入计划模式；带需求时开始规划 |
| `/default` | 返回执行模式 |
| `/permissions`、`/model` | 打开权限或模型选择器 |
| `/status`、`/help` | 打开执行现场或指令菜单 |

目标栏位于输入框上方，支持编辑、暂停、继续与清除。编辑保留原生预算、状态和用量，并检测另一设备的过期修改。`/goal` 是持续目标，不是计划模式。

任务启动或回复中，输入框为空时显示停止；输入文字、添加指令块或附件后变为发送。网页管理的任务会把追加消息放入输入框上方的待发送队列，本轮结束后按顺序执行，并保留每条消息选择的模型、强度、权限与附件。点击队列消息右侧的 × 即可删除，无需停止当前回复；刷新或换设备仍能查看和删除待执行消息。已经开始执行的消息不能撤回，可清空输入框后使用停止按钮。

停止会中断当前执行、取消本地排队消息，并保留和暂停目标；目标暂停/清除会同步停止执行。清除只删除目标，不删除聊天记录。草稿保留。外部客户端执行需在原客户端停止，其原生队列不支持从网页撤回。

默认显示最近 10 条消息和指令记录，上滑到顶部或点击加载提示后展示全部。你发送的文字按原文显示，保留换行、缩进及终端命令中的符号。Codex 回复支持 GFM 表格和 KaTeX 数学公式，宽表格和块级公式可横向滚动。

进入会话或收到新回答时，阅读区域从最新回答的开头显示；回复继续增长、执行结束或窗口尺寸变化时，不会自动跳到回答底部。手动滚动后会保留当前阅读位置，加载更早记录也不会改变正在看的段落。空闲时发送新问题会恢复自动定位；切换会话或刷新页面会定位该会话的最新回答。

公式支持行内 `$...$`、`\(...\)` 和块级 `$$...$$`、`\[...\]`，可包含多行矩阵、`aligned` 等 KaTeX 支持的环境，也可出现在列表和引用中。例如：

```text
行内公式：\(\frac{a}{b}\)。

\[
\begin{aligned}
E &= mc^2 \\
a^2+b^2 &= c^2
\end{aligned}
\]
```

`math` 代码块也会渲染为公式；普通代码块（包括 `latex`、`tex`）和行内代码保留源码。回复分段到达时，公式补齐后会重新渲染；语法错误或 KaTeX 不支持的表达式会保留可读内容，不影响其他消息。这里提供公式排版，不编译完整 LaTeX 文档或加载任意宏包。

## 权限与审批

| 权限 | 作用 |
| --- | --- |
| 只读 | `read-only` + `never` |
| 按需批准（默认） | `workspace-write` + `on-request`，额外操作通过聊天审批卡批准 |
| 完全访问 | `danger-full-access` + `never`，使用服务器用户权限访问文件与网络 |

审批需要用户显式选择批准或拒绝，不自动同意。刷新可恢复尚未处理的请求；过期、重复回复会被拒绝。权限最终执行能力还取决于 Codex CLI、操作系统和沙箱环境。

## 选项与问答

Codex 发出的结构化问题显示在输入区上方，可以点选选项、填写自己的答案，再点击“提交回答”。支持原生问答及 `request_user_input_async`；普通回复中的编号列表不会被当成问题自动提交。

活跃会话的新问题有 30 秒倒计时。到时未提交，服务端使用已同步的选择；未选择的题使用推荐项，没有推荐项则使用第一项。纯文本题未填写时反馈“用户未填写”，不会编造内容。所有超时回复明确标注“系统自动回复”，不能视为用户亲自确认的信息。

倒计时由服务端执行，刷新、切换会话或手机进入后台不会重置。答案会直接投递给当前会话，不等普通消息队列轮到它；如果该轮已经结束，则继续会话处理答案。新一轮开始后，旧的未答问题失效。历史会话首次展示的旧问题只允许手动回复，不自动启动计时。

发送失败会显示重试状态；投递结果无法确认时不重复自动发送，请先查看会话是否收到。Relay 的问答记录只保存处理状态和时间，不保存自由填写答案或口令。

## 文件和绘画

聊天 `/` 菜单的「上传文件」支持图片、PDF、Word、PPT、Excel、OpenDocument、文本、Markdown、CSV/TSV、JSON、RTF 和 ZIP。桌面还可粘贴、拖拽。每条消息最多 6 个附件，图片最多 20 MB / 4000 万像素，文档最多 50 MB。图片格式为 PNG、JPEG、WebP、GIF。

待发送附件在输入框上方的虚线区域，可预览、移除和重试。图片预览支持适应屏幕与原始尺寸；普通文件按原始字节下载。旧版 Office 文件可上传下载，但不保证已有文档库能解析；扫描件识别、密码文档处理需额外工具。Python 环境包含 pypdf、python-docx、python-pptx、openpyxl 和 reportlab，供 Codex 读取或生成常见文档。

要求 Codex 返回工作目录内的 Markdown 文件链接时，会显示附件卡片，例如 `[报告](<绝对文件路径>)`；已导入附件持久保存，源文件移动后仍可下载。工作目录外、隐藏配置、凭据文件等路径不能通过文件返回接口读取。

「绘画参考」提供 8 种颜色、3 档线宽、橡皮、撤销/重做与大画布。「完成并添加图片」将白底 PNG 加入附件，点击发送才提交给模型。未上传的画板草稿只保留在当前页面，刷新会丢失。画板和上传流程本身不调用生图 API。
